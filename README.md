# Claude Code Experiments

A collection of tools and apps built with Claude Code.

## Projects

### [Gmail Monitor](gmail-monitor/)
Monitors Gmail for emails from specific senders and sends instant phone call notifications via Twilio.

### [Dental Cavity Prep Simulator](dental-cavity-prep-simulator/)
Interactive DO Class 2 cavity prep simulator for Irish Dental Council Bench Test preparation. Step-by-step guided mode with SVG visualizations, bur selection, and self-assessment using the actual IDC G/P/B/F marking criteria.
